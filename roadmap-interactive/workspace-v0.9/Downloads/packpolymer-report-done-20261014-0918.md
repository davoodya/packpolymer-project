## فاز ۰ — استراتژی مارکت‌پلیس و برنامه کسب‌وکار پک پلیمر  —  ۵۷٪

### [x] طراحی مدل کسب‌وکار بازارگاه (Marketplace) در کنار فروش مستقیم B2C  (≈ ۳ روز · بنیان‌گذار / مدیر محصول)  «Dokan Pro»
- [x] تعیین کن پک پلیمر خودش فروشنده است یا بازارگاه؛ در واقعیت مدل هیبریدی بهترین جواب است: کاتالوگ و برند ادمین + فروشندگان تأییدشده روی همان صفحه محصول.
- [x] سهم هدف فروش را بین B2C (کیسه ۱ تا ۵ کیلویی، سیلیکون قالب‌گیری، چسب) و B2B (پالت، تنی، قرارداد فصلی) عددی کن؛ مثلاً ۲۵٪ / ۷۵٪.
- [x] سه لایه مشتری را تعریف کن: مصرف‌کننده نهایی (B2C)، کارگاه و تولیدی (B2B خرد)، کارخانه و توزیع‌کننده استانی (B2B عمده).
- [x] سهم «فروش مستقیم ادمین» در برابر «فروش فروشندگان» را از روز اول مشخص کن؛ این تصمیم روی کمیسیون، حمل و پشتیبانی اثر مستقیم دارد.
- [x] جریان‌های درآمدی را بنویس: کمیسیون فروش، اشتراک فروشنده، کرایه حمل، خدمات فنی/مشاوره گرید، تبلیغات فروشنده (Product Advertising)، فروش نمونه.
- [x] سناریوی «چه می‌شود اگر فروشنده تخلف کند» را از الان بنویس: تعلیق فروشگاه، نگه‌داشتن تسویه، اطلاع به خریدار.

### [x] تحقیق بازار و تعریف پرسونای خریدار و فروشنده  (≈ ۴ روز · مارکتینگ)
- [x] ۵ تا ۸ رقیب آنلاین (فروشگاه‌های پلیمر و سیلیکون، بازارگاه‌های عمومی) را در اکسل ثبت کن: نمایش قیمت، کیفیت صفحه محصول، TDS، سرعت، مدل فروش.
- [x] برای هر رقیب بنویس «شکاف» کجاست: فقدان نرخ روز، نداشتن سیلیکون تخصصی، نبود امکان استعلام عمده، نبود بازارگاه چندفروشنده.
- [x] صنایع هدف B2B را لیست کن: بسته‌بندی، لوله و اتصالات، خودرو و قطعات، لوازم خانگی، سیم و کابل، قالب‌سازی سیلیکون، رنگ و پوشش.
- [x] با حداقل ۸ خریدار واقعی صحبت کن و واژه جست‌وجویشان را ثبت کن (گرانول، گلوله، دانه، رزین، خامه، سیلیکون).
- [x] با ۵ تأمین‌کننده/برند صحبت کن و بفهم چرا حاضرند در پک پلیمر بفروشند: دسترسی به مشتری جدید، فروش آنلاین، کاهش بار سؤالات تکراری.
- [x] برای هر پرسونا کارت بساز (نقش، دغدغه، معیار انتخاب، مانع خرید) و Value Proposition را در یک جمله بنویس.

### [x] برنامه جذب فروشنده (Vendor Recruitment) و مدل همکاری  (≈ ۳ روز · مدیر بازارگاه)  «Dokan Pro»
- [x] پروفایل فروشنده ایده‌آل را بنویس: پخش‌کننده رسمی برند، کارخانه ایرانی، واردکننده با مجوز، نمایندگی استانی.
- [x] سه سطح فروشنده تعریف کن: پایه (کمیسیون بالاتر، محدودیت تعداد محصول)، حرفه‌ای (اشتراک ماهانه، کمیسیون کمتر)، استراتژیک (برند، نمایش ویژه).
- [x] بسته معرفی فروشنده بساز: چه می‌گیرد (کانال فروش جدید، پنل، تسویه هفتگی)، چه تعهد می‌دهد (قیمت درست، موجودی، ارسال به‌موقع، TDS).
- [x] لیست ۵۰ فروشنده هدف را با اطلاعات تماس و تصمیم‌گیرنده بساز و برنامه تماس/بازدید بنویس.
- [x] درصد کمیسیون تشویقی برای ۳ ماه اول هر فروشنده جدید تعیین کن (مثلاً کاهش ۱٪ کمیسیون).
- [x] قاعده به‌روزرسانی موجودی را در قرارداد بگذار: فروشنده‌ای که ۳ بار کالای ناموجود بفروشد، به حالت «فقط استعلام» می‌رود.

### [x] KPI بازارگاه: GMV، کمیسیون، فروشنده فعال، نرخ تبدیل RFQ  (≈ ۲ روز · مدیر محصول)
- [x] KPI عرضه: تعداد فروشنده فعال (دارای حداقل ۵ محصول موجود)، تعداد مشتری (SKU) موجود، پوشش دسته‌بندی.
- [x] KPI فروش: GMV، درآمد کمیسیون، تناژ فروش، میانگین ارزش سفارش (AOV) به تفکیک B2B/B2C.
- [x] KPI B2B: تعداد RFQ، نرخ تبدیل RFQ به سفارش، طول چرخه فروش، تعداد مشتری حقوقی فعال.
- [x] KPI عملیات: زمان آماده‌سازی سفارش، نرخ سفارش دیررس، نرخ مرجوعی، نرخ اختلاف (Dispute) بین خریدار و فروشنده.
- [x] هدف عددی ۳ و ۶ ماهه را بنویس و مالک هر KPI را تعیین کن.
- [x] ابزار سنجش را انتخاب کن: GA4 (با ecommerce tracking)، Search Console، گزارش‌های Dokan و FluentCRM.
